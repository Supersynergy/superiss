# Historical benchmark boundary

The JSON files in this directory were produced for the 20 October 2026 multiworker experiment. They compare an earlier 0.8 debug baseline and a 0.9 debug candidate on a synthetic warm workload. They were not rerun for the public launch and do not compare Superiss with the five tools in the market table.

Later service, recovery and default-setting changes mean these numbers must not be described as a current release-wide speed result. Local paths in the original evidence describe that experiment; the public artifact retains measurement values and hashes while replacing machine-specific paths with portable placeholders. A declared historical hash is not an independent execution receipt.

Current source acceptance is recorded in [release validation](../../docs/VALIDATION.md). No claim about customer throughput, cold starts, model costs or production p95 follows from this experiment.
